# Josephs Furniture Frontend

A luxury editorial furniture ecommerce frontend built on the existing React/Vite project.

## New experience
- Luxury sticky navigation with Shop, Collections and Rooms mega menus
- Editorial homepage with hero, categories, new pieces, rooms and luxury edit
- Shop catalogue with category, material, colour, style, room, availability and price filters
- Collection pages
- Room / Shop-the-room pages
- Inspiration / lookbook
- Journal
- Interior design services and consultation form
- Existing cart, checkout, wishlist, account, orders, delivery and payment flows preserved
- Responsive mobile navigation

## Backend compatibility
Product data continues to load from the existing `/api/products/` endpoint. Existing cart, auth, checkout, order and contact endpoints are retained.

## Images
The editorial landing pages use remote Unsplash image URLs as visual placeholders. Replace them with your licensed Josephs Furniture photography before production.

## Start
```bash
npm install
npm run dev
```
